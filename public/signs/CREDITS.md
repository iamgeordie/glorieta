# Sign image credits

The SVG files in this folder are Spanish traffic sign drawings from
[Wikimedia Commons](https://commons.wikimedia.org/wiki/Category:Road_signs_of_Spain).
Most are in the public domain. Two are licensed under Creative Commons
Attribution-ShareAlike and are credited here, as the license requires.

All other files are marked "Public domain" on their Commons file pages. Each
local file is named for its catalogue code (R = regulation, P = warning); the
Commons file it came from is `Spain traffic signal <code without the dash>.svg`,
except `r-2.svg`, which is `Spain traffic signal r2 1992.svg`.
